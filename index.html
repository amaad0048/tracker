Host on GitHub Pages (use on any device)
1. Go to github.com → create free account → New repository → name it tracker → Public

2. Upload this HTML file, rename it index.html

3. Go to Settings → Pages → Branch: main → Save

4. Your URL will be: https://YOUR-USERNAME.github.io/tracker

5. Open that URL on your phone → paste the same Apps Script URL → Save & Connect

Now both devices read and write to the same Google Sheet. Data is always in sync.
⚡ Each device needs internet to work — data lives in Google Sheets, not on the device.
